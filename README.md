# Side projects

Personal side projects, one folder each.

## Claude Code skills

`.claude/skills/` holds three skills that Claude Code loads automatically when you work in this repo:

- `software-factory`: idea to working app through gated phases (intake, requirements, plan, build in slices, validate, ship, change requests)
- `requirements-scenarios`: interview and `SPEC.md` with scenarios, constraints and acceptance criteria
- `acceptance-validation`: prove it works, including on your own machine

Start a project by running `claude` here and asking: "Use the software-factory skill to build X".

## Projects

- [`ai-assistant/`](ai-assistant/): a personal assistant that checks email, tracks budget, workouts and appointments, and acts only with your approval. Runs locally on Windows or Mac.
- [`events-app/`](events-app/): **Afro Social**, a website of local events for the African diaspora. Near-me feed, one-step sharing by link or flyer, AI review, duplicate merging, followed organisers. Prototype, runs locally. Built with the software-factory skills; see its `SPEC.md` and `VALIDATION.md`.
